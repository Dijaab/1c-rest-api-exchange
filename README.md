Интеграция 1С и HTTP API

Проект демонстрирует реализацию двустороннего обмена данными на платформе 1С:Предприятие 8.5 (конфигурация Управление торговлей, редакция 11.5): получение данных из публичного REST API и публикацию собственного HTTP-сервиса.

Клиентская часть — получение курсов валют (API ЦБ РФ)
Файл: ИнтеграцияHTTP.epf (внешняя обработка).
Реализовано установление защищенного HTTPS-соединения (ЗащищенноеСоединениеOpenSSL, HTTPСоединение) с сервером www.cbr-xml-daily.ru, выполнение GET-запроса к /daily_json.js и проверка кода состояния ответа. Выполняется парсинг JSON-строки встроенными средствами платформы (ЧтениеJSON, ПрочитатьJSON) в Соответствие, извлечение актуальных курсов валют и вывод пользователю с обработкой исключений.

Серверная часть — собственный REST HTTP-сервис
Объект конфигурации: HTTP-сервис МойСервис (корневой URL api, маршрут /ping, метод GET).
Выполнена публикация информационной базы на веб-сервере Microsoft IIS и настройка анонимной аутентификации.

Стек технологий: 1С:Предприятие 8.5 (Такси), УТ 11.5, HTTP/HTTPS, REST API, JSON, Microsoft IIS.
